## Implemented Algorithms and Data Structures

- **Binary Insertion Sort**  
  Sorts a table of string keys and values using insertion sort with binary search to find the insertion position.

- **Expression Tree Simplification**  
  Parses arithmetic expressions into an expression tree and removes redundant zero terms such as `x + 0`, `0 + x`, and `x - 0`.

- **General Tree Width**  
  Implements a general tree and calculates its maximum width, meaning the largest number of nodes on the same level.

- **Red-Black Tree**  
  Implements a self-balancing binary search tree with insertion, deletion, search, and tree printing operations.

- **Floyd-Warshall Algorithm**  
  Finds shortest paths between all pairs of vertices in an undirected weighted graph represented as an edge list.
